# 倾斜摄影数据处理

# OSGB优化

1.合并根节点

先使用 Desktop 11i(2022)版本生成scp配置文件

使用超图 iDesktopX 10i 10.0版本进行根节点合并

根节点条数按金字塔层级x4计算，如金字塔层级设置为1，则合并根节点数为原根节点数/4\*1

# 3D Tiles

1.OSGB-3D Tiles

使用CesiumLab将处理好的OSGB数据转成3D Tiles

注意如需数据优化 需在OSGB 阶段进行优化再转换

2.S3M - 3D Tiles

用 SuperMap iDesktop x 11i(2023) 将 S3M1.0数据转为 3D Tiles

注意 仅用 S3M1.0 数据才能用其转为3D Tiles

# S3M

1.OSGB-S3M前端插件可加载版

使用SuperMap iDesktopx 11i(2022) 11.0 进行倾斜摄影入库(几何不压缩，纹理DXT)，完成后生成 S3M 文件前端可加载

2.OSGB-S3M3.0文件压缩版-3D Tiles

**使用SuperMap Desktop 11i 进行倾斜摄影入库 按照最大优化设置，生成 S3M文件可用于转换为3D Tiles**

（仅可转换S3M1.0）

> 正射部分在转成3dtiles后，缩放到一定层级会缺失部分

3.3D Tiles-S3M3.0-倾斜摄影入库

先将3D Tiles 用SuperMap iDesktopx 11i(2022)转为 S3M3.0，再倾斜摄影入库重新入库合并根节点等（可能存在模型丢失问题）

4.S3M 3.0 >S3M 2.0>S3M 1.0
