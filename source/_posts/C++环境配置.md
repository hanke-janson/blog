# C++环境配置

基础环境为 Ubuntu18.04

## 安装g++编译器

```bash
g++ -v
```

若未安装GCC，那么请按照 [http://gcc.gnu.org/install/](http://gcc.gnu.org/install/) 上的详细说明安装GCC。

原源码镜像很慢，建议使用[https://mirrors.tuna.tsinghua.edu.cn/help/gcc.git/](https://mirrors.tuna.tsinghua.edu.cn/help/gcc.git/)
