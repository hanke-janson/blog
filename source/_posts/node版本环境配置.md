# node版本环境配置

## 1. 安装nvm

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

## 2. 安装node

安装最新版LTS

```bash
nvm install --lts
```

列出已安装的 Node.js 版本‌：

```bash
nvm ls
```

‌切换到特定版本的 Node.js‌：

```bash
nvm use 14
```
